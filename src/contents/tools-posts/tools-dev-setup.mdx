## 에디터

**VS Code** + Claude Code 조합을 메인으로 사용합니다. 확장 기능은 최소화하되, ESLint / Prettier / GitLens는 필수입니다.

## 터미널

- **Windows Terminal** — 탭 + 테마 지원
- **pnpm** — npm/yarn 대비 빠른 패키지 매니저

## 브라우저

Chrome DevTools의 Performance / Network 탭을 자주 활용합니다. React DevTools와 함께 쓰면 렌더링 분석이 수월합니다.
