## 2025년 프론트엔드 주요 변화

### React 19

Server Actions, use() 훅, 개선된 Suspense 등으로 풀스택 React 개발이 더 자연스러워졌습니다.

### Tailwind CSS v4

엔진을 Rust로 재작성해 빌드 속도가 획기적으로 빨라졌고, CSS-first 설정 방식을 도입했습니다.

### 번들러 생태계

Vite가 사실상 표준이 되었고, Rolldown(Rust 기반)으로의 전환이 준비 중입니다.
